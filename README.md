## ディレクトリ構成
コードは、画面・機能に近い場所を優先し、複数箇所で使う場合は責務に合った共有先へ配置します。

```text
src/
├── app/                  # ルート、ページ、画面固有のUI
│   └── <page>/
│       └── _components/  # そのページだけで使うUI
├── components/           # 複数の画面で使うUI
├── hooks/                # Reactの状態・ライフサイクルを扱うカスタムHook
├── services/             # Firebaseなど外部サービスとの連携
├── config/               # 複数箇所で使うアプリケーション設定
├── lib/                  # 機能に依存しない処理、外部ライブラリの初期化・薄いラッパー
├── store/                # アプリケーションで共有する状態管理
├── types.ts              # 複数箇所で共有する型
└── instrumentation*.ts   # Next.jsの起動時初期化・計測
```

機能固有の設定や処理は `lib/` に集めず、その機能の責務に合った場所へ置きます。Hook以外の通常関数は `hooks/` に置かず、ファイルは原則として1つの主な責務に絞ります。
